# Elia Moracci — Academic Website

Personal academic website for [Elia Moracci](https://eliamoracci.github.io/website/), hosted on GitHub Pages.

## Structure

- `index.html` — Home (bio, photo, contacts)
- `research.html` — Working papers & publications
- `policy.html` — Policy publications
- `discussions.html` — Conference discussions
- `teaching.html` — Teaching positions
- `css/style.css` — Stylesheet
- `files/` — PDFs (CV, papers, slides)

## Deploy

Push to `master` — GitHub Pages serves the HTML directly. No build step needed.
